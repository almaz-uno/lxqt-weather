== R3 — the Nominatim usage policy

`https://operations.osmfoundation.org/policies/nominatim/`, read 2026-10-01:

* at most one request per second;
* a User-Agent or Referer identifying the application — not a library's
  default;
* results cached on the client;
* no client-side autocomplete, no systematic queries;
* attribution suitable for the medium, data under ODbL;
* a client application must be able to switch the service at the
  foundation's request without a software update.

The widget makes one request per OK of the settings dialog, stores the
result, names itself in the User-Agent, attributes the data in the dialog, and
takes the service from the key `geocoder_url`.
