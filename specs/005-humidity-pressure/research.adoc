== R2 — the wind of `current_weather`

The same place, 14:45: `current_weather` gives `windspeed` 10.7 with the unit
`km/h` (`current_weather_units`), while `current` with `wind_speed_unit=ms`
gives 2.97 m/s; 10.7 / 3.6 = 2.97. The tooltip prints the number of
`current_weather` with "m/s" — 3.6 times the real speed.

== R3 — the size of the response

The same place, 2026-10-02: the request of 0.2.0 — `current_weather`,
`hourly` with three variables, `daily` with three — 5847 bytes; the request of
the specification — `current` with six variables — 580 bytes.

== R4 — millimetres of mercury

1 mmHg = 133.322387415 Pa, so 1 hPa = 0.750061576 mmHg: 1007.3 hPa = 755.54,
rounded to 756; the standard atmosphere, 1013.25 hPa, is 760.00 mmHg.
